# Mapa de la documentación

| Documento | Qué contiene | Léelo cuando |
| --- | --- | --- |
| `producto.md` | Qué es el producto, para quién, alcance | Necesites contexto de negocio |
| `glosario.md` | Términos del dominio y su nombre en código | Nombres entidades o casos de uso |
| `estado.md` | Paso actual y pendientes (se carga siempre) | — |
| `adr/README.md` | Índice de decisiones, una línea cada una | Antes de proponer cambios de arquitectura |
| `fases/README.md` | Índice de fases y su estado | Inicies o cierres una fase |
| `fases/fase-N.md` | Objetivo, alcance y criterio de salida de la fase N | Trabajes en esa fase |
| `specs/<funcionalidad>/` | requisitos.md, diseno.md, tareas.md | Implementes o revises esa funcionalidad |
| `security/` | Amenazas, clasificación de datos, registro LOPDP | Toques datos personales o autenticación |
| `fase0/base-tecnica.md` | Stack y principios completos de la Fase 0 | Dudes de una decisión técnica de base |
| `fase0/ruta-crecimiento.md` | Qué se agrega y cuándo | Un cliente o una medición pida algo nuevo |
| `guia-contexto.md` | Cómo está organizado el contexto de Claude | Agregues reglas, skills o documentación |
