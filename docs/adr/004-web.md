# ADR 004: Web — React + Next.js

## Estado
Aceptado — Fase 0, paso 0.1 (2026-10-01)

## Contexto
La web debe reusar tipos y lógica con el backend TypeScript (ADR 002) y con la app móvil React Native (ADR 005), y seguir patrones tipo ClickUp (barra lateral, paleta de comandos, múltiples vistas) con alta densidad de información.

## Decisión
Web en **React + Next.js**. Comparte lenguaje y parte del ecosistema (hooks, librerías) con backend y móvil, y permite renderizado híbrido (SSR/CSR) según la pantalla.

## Alternativas consideradas
- **SPA pura (Vite + React sin framework de servidor):** más simple, pero pierde SSR/rutas de archivo y convenciones que Next.js ya resuelve, a costo de más configuración manual en un plazo corto.
- **Otro framework (Vue, Svelte):** no comparte ecosistema de componentes con React Native/Expo (ADR 005), duplicando esfuerzo de UI entre web y móvil.

## Consecuencias
- `apps/web` consume los contratos OpenAPI generados desde el backend.
- El sistema de diseño (ADR 019: tokens + Tailwind + shadcn/ui) se integra de forma nativa con React.
- Las vistas lista/tablero de órdenes de servicio (paso 0.6) y las pantallas plantilla (paso 0.5) se construyen sobre esta base.
